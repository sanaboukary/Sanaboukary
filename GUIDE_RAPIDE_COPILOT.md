# Guide Rapide - GitHub Copilot dans VSCode

## 🚀 Installation en 3 étapes

1. **Installer l'extension** : Ouvrez VSCode → Extensions (`Ctrl+Shift+X`) → Recherchez "GitHub Copilot" → Installez
2. **Se connecter** : Cliquez sur "Sign in to GitHub" et autorisez l'accès
3. **Vérifier** : Icône Copilot en bas à droite avec une coche ✓

## ⚡ Raccourcis essentiels

| Action | Raccourci |
|--------|-----------|
| Accepter la suggestion | `Tab` ou `Ctrl+Enter` |
| Suggestion suivante | `Alt+]` |
| Suggestion précédente | `Alt+[` |
| Ouvrir le chat | `Ctrl+Shift+I` |
| Éditeur inline | `Ctrl+I` |

## 💬 Commandes du chat

- `/explain` - Expliquer le code sélectionné
- `/fix` - Corriger les problèmes
- `/tests` - Générer des tests
- `/doc` - Générer la documentation

## 🎯 Exemples rapides pour ce portfolio

### Ajouter un nouveau projet
```
Dans le chat Copilot :
"Génère le HTML pour un nouveau projet d'analyse de données avec le même style que les projets existants"
```

### Améliorer le design
```css
/* Dans styles.css, ajoutez ce commentaire : */
/* Améliore l'animation au survol des cartes de projet */
```
Puis appuyez sur `Entrée` - Copilot générera le code CSS !

### Ajouter une fonctionnalité
```javascript
// Dans script.js, écrivez :
// Fonction pour filtrer les projets par technologie
```
Copilot générera automatiquement la fonction complète.

### Mode sombre
```
Dans le chat :
"Ajoute un bouton toggle pour basculer entre le mode clair et sombre avec animation smooth"
```

### Optimiser les images
```
@workspace Comment optimiser le chargement des images dans ce portfolio ?
```

## ✅ Checklist pour débuter

- [ ] Extensions GitHub Copilot et GitHub Copilot Chat installées
- [ ] Connecté à votre compte GitHub
- [ ] Icône Copilot active en bas à droite de VSCode
- [ ] Testé l'autocomplétion avec un commentaire
- [ ] Ouvert le chat Copilot (`Ctrl+Shift+I`)
- [ ] Essayé une commande `/explain` sur du code
- [ ] Utilisé `@workspace` pour une question sur le projet

## 🆘 Problème ?

- **Copilot ne suggère rien** → Vérifiez l'icône en bas à droite, reconnectez-vous
- **Suggestions non pertinentes** → Soyez plus précis dans vos commentaires
- **Erreur de connexion** → Vérifiez votre abonnement GitHub Copilot
